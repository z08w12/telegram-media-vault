# 第一版功能与验收清单

## 核心闭环

- [x] 授权用户可以向 Bot 发送或转发图片、视频、动画和文件。
- [x] Bot 将文件下载到 VPS，并反馈成功、重复或失败状态。
- [x] 向 Bot 发送公开 X/Twitter 帖子链接并转存帖子中的视频。
- [x] 网页媒体库读取同一份文件和元数据。
- [x] 管理员登录后可以预览、播放、下载和管理媒体。

## 数据与可靠性

- [x] 使用 SQLite 记录 Telegram 标识、来源、说明、文件信息和状态。
- [x] 使用 Telegram 消息与文件唯一标识防止重复入库。
- [x] 先写临时文件，完成后原子移动到媒体目录。
- [x] 下载失败时删除临时文件并记录错误。
- [x] 文件按媒体类型和年月分层保存。
- [x] 进程崩溃由 systemd 自动重启，服务提供健康检查。

## 网页媒体库

- [x] 响应式图片与视频卡片布局。
- [x] 类型筛选、文字搜索、收藏和分页。
- [x] 图片原图查看和视频分段播放。
- [x] 图片全屏预览，支持电脑键盘、按钮和手机滑动切换。
- [x] 原文件下载和来源信息查看。
- [x] 回收站、恢复、永久删除和自动清理。
- [x] 文件数量、媒体数量和空间占用统计。
- [x] 彩色标签管理、自动提取、单项编辑和组合筛选。
- [x] 自定义相册创建、编辑、删除、封面、成员管理和筛选。
- [x] 批量选择、标签与相册调整、收藏、回收站、恢复和永久删除。

## 安全

- [x] Telegram 用户 ID 白名单。
- [x] 网页密码登录、签名会话、HttpOnly 与 SameSite Cookie。
- [x] 登录失败限速。
- [x] 媒体必须经过登录保护的接口读取。
- [x] 文件路径越界防护。
- [x] Nginx、Certbot HTTPS 和基础安全响应头。
- [x] Token、密码和签名密钥由环境变量注入。

## 后续版本

- [ ] Cloudflare R2 存储适配器与现有媒体迁移。
- [x] Telethon MTProto Bot 大文件接收模式。
- [ ] 自动转码为浏览器兼容格式。
- [ ] 公开分享链接。
